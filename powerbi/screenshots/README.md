# Power BI Dashboard Visual Specifications & Screenshots

This folder hosts visual design references, mockups, and exported report screenshots for the Power BI platform:

1. **`01_Executive_Overview.png`**: High-level supply chain executive KPI summary, risk distribution, and urgent purchase orders.
2. **`02_Demand_Forecast_Analysis.png`**: Out-of-sample forecast trajectories with 95% confidence intervals, decomposition tree, and day-of-week patterns.
3. **`03_Forecast_Performance_Bias.png`**: Champion-Challenger model benchmark (LightGBM vs Baselines) and bias tracking.
4. **`04_Inventory_Health_ABC_XYZ.png`**: 9-Box portfolio matrix, days of supply distribution, and holding cost exposure.
5. **`05_Reorder_Recommendations.png`**: Daily operational procurement action matrix with priority scoring.
6. **`06_What_If_Scenario_Analysis.png`**: Supply chain stress-testing simulations and capital delta waterfall.
